# House of Decor

A premium interior design company website — elegant, responsive, and built for a real client.

## 🌐 Live Site
[View on Netlify](https://houseofdecor.netlify.app/)

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript
- Nicepage (used for initial layout scaffolding)

## ✨ Features
- Premium, modern aesthetic
- Fully responsive (mobile / tablet / desktop)
- Custom navigation and hero sections
- Contact form with international phone input

## 🎯 About This Project
Built for **House of Decor**, a premium interior design company.
Currently hosted on Netlify while the client finalizes their domain and hosting.

## 📌 Status
Live demo available. Client hosting pending.
